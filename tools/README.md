# Local tools and runtimes

Qiansi-Canvas keeps program dependencies under `tools/` so `data/` remains
reserved for projects, assets, user settings, and other user-owned content.

- `runtime/node/windows/`: verified project-local Node.js for Windows.
- `runtime/node/macos/`: verified project-local Node.js for macOS.
- `cache/npm/`: reusable npm download cache for source development only.

The runtime and cache directories are generated by the installers and are not
tracked as source files. End-user portable releases contain only the fixed Node
executable and its license; they do not contain npm, `node_modules`, TypeScript,
Vite, or an npm cache. Source development continues to use root `node_modules/`
because Node.js package resolution expects that standard layout.

## Media tools

This directory contains the portable Windows executables used by Qiansi-Canvas
to inspect and process imported media without requiring a system-wide install.

- `ffprobe.exe`: validates audio/video streams before an asset is accepted.
- `ffmpeg.exe`: generates previews, extracts frames, and exports local media.
- `FFmpeg-README.txt`: upstream build and license information.

Source: https://www.gyan.dev/ffmpeg/builds/

The Windows build provider is linked from the official FFmpeg download page:
https://ffmpeg.org/download.html
